# Handoff Skill — 无缝衔接

通用的 Codex Skill，用于在更换聊天/对话时自动生成交接文档。

## 触发词

"写无缝衔接" / "写交接" / "换聊天" / "无缝衔接" / "handoff" / "交接文档" / "写交接文档"

## 产出文件

- `AGENTS_HANDOFF.md` — 精简版，持续覆盖更新
- `HANDOFF_{YYYY-MM-DD}_{简述}.md` — 详细版，每次新建

## 工作流程

1. 自动探测项目环境（技术栈、服务架构、git 状态）
2. 查询知识库补充历史上下文
3. 生成/更新交接文档
4. 回写关键信息到知识库

## 安装

```bash
cp -r handoff-skill ~/.codex/skills/
```

安装后在任意项目中说出触发词即可使用。
